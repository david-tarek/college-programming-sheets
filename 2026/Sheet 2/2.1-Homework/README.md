### ملاحظة عن نوع `name`

نص السؤال يذكر أن `name` من النوع `int`، لكن الحل الحالي يستخدم `string` لأن الاسم في الواقع نص، وهذا يجعل الإدخال والعرض أوضح.

لو المطلوب هو الالتزام الحرفي بنص السؤال، يمكن تغيير:

```cpp
string name;
```

إلى:

```cpp
int name;
```

مع إرجاع قراءة الاسم إلى:

```cpp
cin >> name;
```

## السؤال الثاني — Class للإحصاء حسب القسمة

### المطلوب

كتابة برنامج يحتوي على `class Data` بالبيانات التالية:

- `X[30]` من النوع `float`
- `h` من النوع `int`
- `T[30]` من النوع `string`
- `n` عدد عناصر `X` و`T`

والدوال التالية:

- دالة لقراءة البيانات، وتحديد كل عنصر في `T`:
  - `"Yes"` إذا كان `X[i]` يقبل القسمة على `h`.
  - `"No"` خلاف ذلك.
- دالة ترجع مجموع عناصر `X` التي لا تقبل القسمة على `h` باستخدام `T`.
- دالة ترجع متوسط عناصر `X` التي تقبل القسمة على `h` باستخدام `T`.
- دالة لعرض البيانات.
- دالة للمقارنة بين متوسطات `X` لكائنين وعرض الكائن صاحب القيمة الأكبر.

وفي `main` يتم تعريف كائنات من `Data` واستدعاء كل الدوال عليها.

### شرح الحل

#### 1. `Data::Read()`

- تتحقق من أن `h` لا يساوي صفرًا، لأن القسمة على صفر غير صحيحة.
- تتحقق من أن `n` بين `1` و`30`.
- تقرأ عناصر `X`.
- تحدد قيم `T` تلقائيًا:

```cpp
if (fmod(X[i], h) == 0.0f) {
  T[i] = "Yes";
} else {
  T[i] = "No";
}
```

> نستخدم `fmod` لأن `X` من النوع `float`، والمعامل `%` في C++ يعمل مع الأعداد الصحيحة فقط.
>
> مثال: `2.5` مع `h = 2` لا تقبل القسمة، لذلك تكون `T = "No"`. لو استخدمنا `%` بعد تحويل `2.5` إلى `int`، ستصبح `2 % 2 == 0` وتكون النتيجة `"Yes"` بشكل خاطئ.

- لا نقرأ `T` من المستخدم، لأن المطلوب هو **تحديدها** بناءً على `X` و`h`.

#### 2. `Data::Sum()`

- تمر على كل العناصر.
- إذا كانت `T[i] == "No"`، تضيف `X[i]` إلى المجموع.
- ترجع المجموع النهائي.

#### 3. `Data::Avg()`

- تمر على العناصر التي قيمتها `"Yes"`.
- تجمعها في `sum` وتزيد `count`.
- إذا كان `count == 0`، ترجع `0.0f` لأن لا توجد عناصر تقبل القسمة.
- غير ذلك، ترجع:

```cpp
sum / count;
```

> بدون التحقق من `count == 0` ستحدث قسمة على صفر، وقد تظهر النتيجة `nan`.

#### 4. `Data::Display()`

- تعرض:
  - `h`
  - `n`
  - كل عنصر `X[i]` مع القيمة المقابلة `T[i]`

#### 5. `Data::Compare(Data obj)`

- دالة عضو داخل الكلاس.
- عند استدعائها بهذا الشكل:

```cpp
obj1.Compare(obj2);
```

- يكون `this` هو `obj1`.
- ويكون `obj` نسخة من `obj2`.
- لذلك:

```cpp
Avg()
```

تعني:

```cpp
obj1.Avg()
```

و:

```cpp
obj.Avg()
```

تعني:

```cpp
obj2.Avg()
```

- إذا كان متوسط `obj1` أكبر، تعرض `obj1`.
- إذا كان متوسط `obj2` أكبر، تعرض `obj2`.
- إذا كان المتوسطان متساويين، تعرض رسالة تساوٍ.

> يمكن تمرير الكائن بالمرجع `const Data&` لتجنب نسخه، لكن النسخة الحالية صحيحة وتؤدي نفس النتيجة.

#### 6. `main`

- يعرّف كائنين: `obj1` و`obj2`.
- يقرأ بيانات كل كائن.
- يعرض بيانات كل كائن.
- يطبع مجموع العناصر غير القابلة للقسمة.
- يطبع متوسط العناصر القابلة للقسمة.
- يستدعي `obj1.Compare(obj2)`.
