## السؤال الأول — Class Data: Factorials, Primes, Sum and Product

### المطلوب

كتابة برنامج يحتوي على `class Data` بالبيانات التالية:

- `D[30]` من النوع `float`
- `T[10]` من النوع `char`
- `n` عدد عناصر `D` و`T`

والدوال التالية:

- دالة ترجع factorial لعدد صحيح موجب.
- دالة تختبر إذا كان عدد صحيح أوليًا أم لا.
- دالة لقراءة البيانات وتحديد كل عنصر في `T`:
  - `'Y'` إذا كان `D[i]` عددًا أوليًا.
  - `'N'` إذا كان `D[i]` غير أولي.
- دالة ترجع مجموع `D[i]!` للعناصر التي `D[i]` أولي، باستخدام `T`.
- دالة ترجع حاصل ضرب `D[i]!` للعناصر التي `D[i]` غير أولي و`D[i] != 0`، باستخدام `T`.
- دالة لعرض البيانات في جدول.

وفي `main` يتم تعريف object من `Data` واستدعاء كل الدوال عليه.

### شرح الحل

#### 1. `Fact(num)`

- تبدأ من `fact = 1`.
- تضرب من `1` حتى `num`.
- إذا كان `num < 0` ترجع `0`.
- `Fact(0)` ترجع `1`، و`Fact(5)` ترجع `120`.

```cpp
int Fact(int num) {
  int fact = 1;

  if (num < 0) {
    return 0;
  }

  for (int i = 1; i <= num; i++) {
    fact *= i;
  }

  return fact;
}
```

> الدالة ترجع `int`، لذلك القيم الكبيرة جدًا قد تسبب overflow. القيم المستخدمة في الشيت صغيرة.

#### 2. `Prime(num)`

- الأعداد الأقل من `2` ليست أولية.
- تختبر القسمة على الأعداد من `2` حتى `num - 1`.
- لو وجدت أي قاسم، ترجع `false`.
- لو لم تجد، ترجع `true`.

```cpp
bool Prime(int num) {
  if (num < 2) {
    return false;
  }

  for (int i = 2; i < num; i++) {
    if (num % i == 0) {
      return false;
    }
  }

  return true;
}
```

#### 3. `Read()`

- تقرأ `n`.
- تقرأ عناصر `D`.
- تحول `D[i]` إلى `int` قبل اختبار الأولية، لأن `Prime` و`Fact` يتعاملان مع أعداد صحيحة.
- تحدد `T[i]` مباشرة:

```cpp
if (Prime((int)D[i])) {
  T[i] = 'Y';
} else {
  T[i] = 'N';
}
```

> `T` حجمها `10`، لذلك `n` لازم يكون من `1` لـ`10`. الحل الحالي يفترض أن المستخدم يدخل قيمة صحيحة في هذا المدى.

#### 4. `Sum()`

- تمر على كل العناصر.
- إذا كانت `T[i] == 'Y'`، تضيف `Fact((int)D[i])` إلى المجموع.
- ترجع المجموع كـ`float`.

```cpp
sum += Fact((int)D[i]);
```

#### 5. `Prod()`

- تبدأ بـ`Product = 1`.
- تمر على كل العناصر.
- تضرب فقط العناصر التي:
  - `T[i] == 'N'`
  - و`D[i] != 0`
- تستخدم `Fact((int)D[i])`.

```cpp
if (T[i] == 'N' && D[i] != 0) {
  Product *= Fact((int)D[i]);
}
```

> لو لا توجد عناصر غير أولية وغير صفرية، يكون الناتج `1`، لأن حاصل ضرب مجموعة فارغة يساوي `1`.

#### 6. `Display()`

- تعرض عدد العناصر `n`.
- تعرض جدولًا يحتوي على:
  - `Index`
  - `D`
  - `T`
- تعرض بعد الجدول:
  - مجموع factorials العناصر الأولية.
  - حاصل ضرب factorials العناصر غير الأولية وغير الصفرية.

#### 7. `main`

- يعرّف object واحدًا:

```cpp
Data obj;
```

- يستدعي:

```cpp
obj.Read();
obj.Display();
```

### مثال

الإدخال:

```text
Enter n: 3
Enter 3 values for D (non-negative integers):
2 3 4
```

النتيجة:

```text
Number of elements: 3
---------------------
Index   D   T
---------------------
1       2   Y
2       3   Y
3       4   N
---------------------

Sum of factorials of prime elements = 8
Product of factorials of non-prime non-zero elements = 24
```

الحساب:

```text
Sum  = 2! + 3! = 2 + 6 = 8
Prod = 4! = 24
```

ولو أضفنا `0`:

```text
D = 2 3 4 0
```

فإن `0` لا يدخل في `Prod`، لأن الشرط `D[i] != 0`.

### ملاحظات

- `D` من النوع `float`، لكن القيم المستخدمة هنا أعداد صحيحة غير سالبة.
- `T[10]` تحدد الحد الأقصى لـ`n`، وهو `10`.
- لا توجد حماية من إدخال `n` أكبر من `10` في الكود الحالي؛ لازم يكون الإدخال في المدى الصحيح.
- إذا كانت قيمة `D[i]` كبيرة جدًا، فإن `Fact` قد تسبب overflow لأنها ترجع `int`.

## السؤال الثاني — Struct Point and Class Point_3D

### المطلوب

كتابة برنامج يحتوي على:

```cpp
struct Point {
  float x, y, z;
};
```

ثم `class Point_3D` بالبيانات التالية:

- `P[30]` من النوع `Point`
- `N[30]` من النوع `float`
- `m` عدد عناصر `P` و`N`

والدوال التالية:

- دالة لقراءة البيانات، وتحديد كل `N[i]` بحيث تكون norm للنقطة `P[i]`.
- دالة ترجع المسافة بين أول نقطة وآخر نقطة في `P`.
- دالة ترجع أكبر norm في `N`.
- دالة تقارن بين أكبر norm لكائنين، وترجع الكائن صاحب أكبر norm.
- دالة ترجع أقل مسافة بين أول وآخر نقطة لكائنين.
- دالة لعرض البيانات في جدول.

وفي `main` يتم تعريف objectين من `Point_3D` واستدعاء كل الدوال عليهما.

### شرح الحل

#### 1. Norm وDistance

**Norm** هي طول النقطة من نقطة الأصل `(0, 0, 0)`:

```text
N = sqrt(x² + y² + z²)
```

**Distance** هي المسافة بين نقطتين:

```text
d = sqrt((x1 - x2)² + (y1 - y2)² + (z1 - z2)²)
```

#### 2. `Read()`

- تتحقق من أن `m` بين `1` و`30`.
- تقرأ إحداثيات كل نقطة.
- تحسب `N[i]` مباشرة:

```cpp
N[i] = sqrt(pow(P[i].x, 2) +
            pow(P[i].y, 2) +
            pow(P[i].z, 2));
```

> `N` لا تُقرأ من المستخدم؛ هي ناتج حسابي.

#### 3. `Distance()`

- تأخذ أول نقطة `P[0]`.
- تأخذ آخر نقطة `P[m - 1]`.
- تحسب الفرق في كل إحداثي، ثم تطبق قانون المسافة.

```cpp
dx = P[0].x - P[m - 1].x;
dy = P[0].y - P[m - 1].y;
dz = P[0].z - P[m - 1].z;

distance = sqrt(pow(dx, 2) + pow(dy, 2) + pow(dz, 2));
```

#### 4. `MaxNorm()`

- تبدأ بافتراض أن `N[0]` هي أكبر قيمة.
- تمر على كل العناصر.
- إذا وجدت `N[i]` أكبر، تحدّث `max`.
- ترجع `max` في النهاية.

#### 5. `Compare(other)`

- الدالة عضو داخل الكلاس.
- عند استدعائها بالشكل:

```cpp
obj1.Compare(obj2);
```

- يكون `this` هو `obj1`.
- ويكون `other` نسخة من `obj2`.
- لذلك:

```cpp
MaxNorm()
```

تعني:

```cpp
obj1.MaxNorm()
```

و:

```cpp
other.MaxNorm()
```

تعني:

```cpp
obj2.MaxNorm()
```

- إذا كان `MaxNorm()` أكبر، ترجع `*this`، أي الكائن الحالي.
- غير ذلك، ترجع `other`.

```cpp
Point_3D Compare(Point_3D other) {
  return (MaxNorm() > other.MaxNorm() ? *this : other);
}
```

> عند التساوي، الكود الحالي يرجع `other`. هذا سلوك مقبول لأن الكائنين لهما نفس أكبر norm. لو أردت إرجاع الكائن الحالي عند التساوي، استخدم `>=` بدل `>`.

#### 6. `MinDistance(other)`

- تحسب مسافة أول-آخر للكائن الحالي:

```cpp
float D1 = Distance();
```

- تحسب مسافة أول-آخر للكائن الآخر:

```cpp
float D2 = other.Distance();
```

- ترجع الأصغر:

```cpp
return (D1 < D2 ? D1 : D2);
```

> التفسير المستخدم هنا: كل object له مسافة بين أول نقطة وآخر نقطة، والدالة تقارن المسافتين وترجع الأصغر. لو كان المطلوب هو المسافة بين أول نقطة في الكائن الأول وأول نقطة في الكائن الثاني، والمسافة بين آخر نقطة في الأول وآخر نقطة في الثاني، ثم إرجاع الأصغر، فإن الدالة تختلف.

#### 7. `Display()`

- تعرض جدولًا يحتوي على:
  - `Index`
  - `X`
  - `Y`
  - `Z`
  - `Norm`
- تعرض أيضًا:
  - `Max Norm`
  - `Distance First-Last`

#### 8. `main`

- يعرّف objectين:

```cpp
Point_3D obj1;
Point_3D obj2;
```

- يقرأ بيانات كل object.
- يعرض بيانات كل object.
- يستدعي `Compare` ويخزن الناتج في object جديد.
- يعرض الكائن صاحب أكبر norm.
- يستدعي `MinDistance` ويطبع الناتج.

### مثال

#### Object A

```text
m = 2
Point 1 = 3 4 0
Point 2 = 0 0 0
```

الحساب:

```text
N1 = sqrt(3² + 4² + 0²) = 5
N2 = 0
Max Norm A = 5
Distance first-last A = 5
```

#### Object B

```text
m = 2
Point 1 = 1 2 2
Point 2 = 0 0 0
```

الحساب:

```text
N1 = sqrt(1² + 2² + 2²) = 3
N2 = 0
Max Norm B = 3
Distance first-last B = 3
```

#### المقارنة

```text
Max Norm A = 5
Max Norm B = 3
```

الكائن صاحب أكبر norm هو **A**، لذلك `Compare` ترجع `A`.

#### أقل مسافة

```text
Distance A = 5
Distance B = 3
```

أقل مسافة = `3`.

### شكل الجدول

```text
=====================================
                Data
=====================================
Index   X   Y   Z   Norm
-------------------------------------
1       3   4   0   5
2       0   0   0   0
------------------------------------
Max Norm = 5
Distance First-Last = 5
```

### ملاحظات

- `m` لازم يكون من `1` لـ`30`.
- لو `m = 1`، فأول نقطة وآخر نقطة هما نفس النقطة، والمسافة تساوي `0`.
- `N` هي norm، وليست مسافة بين نقطتين.
- `Compare` ترجع object كامل، وليس رقمًا؛ لذلك نوعها `Point_3D`.
