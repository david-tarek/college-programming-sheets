# Sheet 1 — Functions and Array Operations

This sheet practises user-defined functions, number operations, and one-
dimensional arrays.

## Questions

### `question-01.cpp` — Number Operations

- **1(a)** `isDivisible(a, b)`: test whether two integer numbers are divisible
  by each other.
- **1(b)** `gcd(a, b)`: return the greatest common divisor of two integer
  numbers, converting negative values to positive first.
- **1(c)** `isPrime(number)`: test whether a given float number is prime.
- **1(d)** `reverseNumber(number)`: reverse the digits of a given integer.
- **1(e)** `countDigits(number)`: return the number of digits in a given
  number.

`main()` calls every function with several input variables.

### `question-02.cpp` — Array Operations

- **2(a)** `readArray(arr, size)`: read an array of `n` numbers.
- **2(b)** `displayArray(arr, size)`: display the array.
- **2(c)** `searchNumber(arr, size, target)`: search for a number in the array.
- **2(d)** `replaceNumber(arr, size, oldValue, newValue)`: replace a number with
  another one using the search function.
- **2(e)** `swapNumbers(a, b)`: swap two numbers.
- **2(f)** `sortArray(arr, size)`: sort the array in ascending order using the
  swap function.

`main()` defines three arrays and calls all functions on them.

### `question-03.cpp` — Array Analysis

- **3(a)** `readArray(arr, size)`: read an array of `n` numbers.
- **3(b)** `displayList(arr, size)`: display the array in a list format.
- **3(c)** `reverseArray(arr, size)`: reverse the elements of the array.
- **3(d)** `countOccurrences(arr, size, target)`: return how many times a number
  appears in the array.
- **3(e)** `buildPrefixSums(arr, size, result)`: build an array where each
  element is the sum of all elements from index `0` up to that index.

`main()` defines two arrays and calls all functions on them.
