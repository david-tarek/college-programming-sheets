## Suggested Order

1. Functions: one Arabic video, then the English video if needed.
2. Arrays: Elzero #038, then the Cherno video.
3. Default arguments and function overloading: one Arabic and one English
   video for each.
4. Structs: the Arabic El Desouki video, then Bro Code.
5. Return to the sheet and solve it question by question.

Number algorithms such as GCD, prime testing, digit reversal, and series are
not separate language features. They are built from loops and functions, so
they will be explained while solving the relevant sheet.
